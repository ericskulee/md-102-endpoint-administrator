## Environment

MD-102 labs run in a Microsoft 365 tenant with Intune, Entra ID P2, and Defender for Endpoint. Two ways to get one: the Microsoft 365 Developer Program (requires a qualifying Visual Studio Professional/Enterprise subscription, or ISV Success/MAICPP membership), or a time-limited Microsoft 365 E5 trial. No cloud resource charges either way — plan for ~10–12 hours of lab time within your tenant's active window. Each project's cost alert is replaced with a trial-status reminder.
